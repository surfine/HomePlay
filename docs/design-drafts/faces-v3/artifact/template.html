逐款檢討

左邊是 HomePlay 目前的錶面。官方截圖受版權保護，只放在本機的對照版，這裡改用文字描述。

Island 對 Portraits：材質我們的數字是一條細白描邊包著灰心，讀起來是空心字；官方是整塊實心霜玻璃。
字重與位置官方用 Compressed Semibold，頂到上緣，人站在數字前面。我們的字細，而且置中，一定會擋到臉。
多餘元素日期和「重按連上 iPhone」官方都沒有，操作說明不該印在錶面上。膠囊壓在數字正中央，擋住了時間。
Modular：網格被打破膠囊浮在兩排中間，不屬於任何一格；應該住進其中一格。
字重不一「24」用 Heavy，「100%」卻是細字。官方只有兩級：大字 Semibold／Heavy，小字 Semibold。
像 App 圖示藍色 CarPlay 方塊是 App 圖示的語言，不是小工具。官方左下是正在播放：封面、曲名、灰色膠囊「Play」。
Flow：像貼紙我們用 SF Rounded Heavy 加白描邊和平塗漸層。官方的數字被吹成鼓起的水珠，0 沒有字腔，旁邊還有衛星小水珠。水珠內部會強烈折射背後的粉藍漩渦。
Analog 對 Typograph：最接近數字疊壓、綠底、白指針都做到了。
要改膠囊要退到角落，指針從它上面掃過。指針要做成 Apple 的樣式：細頸接粗桿、帶一點陰影。秒針要更細，並貫穿全高。
床頭：太刺眼紅色霓虹細字有光暈，夜裡反而不平和。改成「黑」錶面：夜間闔眼，只浮出暗紅、無光暈的時間。
Pocket：和 Modular 重複電量卡又和背景的玻璃材質不一致。併進 Modular。

膠囊的三個問題

問題說明
只有一種材質不管哪個年代的錶面都是同一顆不透明黑膠囊。玻璃年代的錶面配純黑，像把舊零件裝到新機器上。
每款貼同一顆位置、大小每款都一樣：Island 擋到時間、照片款擋到臉、Modular 打破網格、Typograph 壓在指針的路上。
眼皮靠塗黑程式裡的眼皮和笑眼是用黑色塗出來的，只能活在黑膠囊裡。要換成玻璃或漸層，眼皮得改成把眼睛形狀切掉。

Home Modular 和 HomeKit

已在這台 Mac 實測打通

macOS 上的 HomeKit 只開放給 Mac Catalyst App，而且要帶 com.apple.developer.homekit 權限和描述檔；用 Developer ID 公開發布的 HomePlay.app 本身帶不了這個權限。所以另外做一個背景小幫手「HomePlay Home」，用開發簽名讀家庭，再透過本機 socket 把狀態交給桌寵。資料不會離開這台 Mac。

試法結果
原生 AppKit 連結 HomeKit做不到：SDK 只在 iOSSupport 裡有 HomeKit（Catalyst 專用）
Catalyst，不帶權限能啟動，但一個家庭都讀不到
Catalyst，帶權限，ad-hoc 簽名一啟動就被 AMFI 殺掉：受限權限一定要有描述檔
Catalyst，開發簽名（已註冊這台 Mac）成功：讀到「我的家」27 個配件、名稱和連線狀態
Developer ID 發布社群回報：Mac Catalyst 的 Developer ID 描述檔不提供 HomeKit
路線誰能用狀態
開發簽名的小幫手註冊在團隊下的 Mac（每年 100 台）已完成：即時讀到 27 個配件、7 個房間、7 個場景，可訂閱變化；桌寵端已能連線，尚未接到錶面
App Store 上架小 App所有人公開版的路；要過審核，本身得有像樣的家庭介面
捷徑橋接所有人，免權限退路：較慢，要使用者匯入捷徑
私有 API只有關掉 SIP 的 Mac不採用：無法給一般使用者

實作順序

  1. 眼皮改成切形：drawEye 的眼皮和笑眼改用裁切，不再塗黑；👀 的畫法不變。
  2. 膠囊材質：新增純黑、黑透漸層、玻璃三種材質和 Siri 聆聽外光，玻璃走 SystemGlass 管線。設定 › 外觀加一個「膠囊」選項：自動／純黑／黑透漸層／玻璃。
  3. 放置：每款錶面回報膠囊的位置、寬度、材質和層級（在主體前或後、在指針下），照上表。
  4. 玻璃字：Portraits 改用 Compressed Semibold、頂到上緣，拿掉日期和「重按連上」；後者改成第一次啟動時的一次性提示。
  5. 新錶面：眼睛、天氣、行事曆、浮雕指針、黑、Growth，並重做 Modular、Flow、Typograph；Pocket 併進 Modular。
  6. System 6 系列：Finder、Alarm Clock、Welcome、About 四款，原生 1-bit 繪製；隨包 ChicagoFLF（下載前先問你）。
  7. Home Modular：接上 HomePlay Home 小幫手的即時狀態。
  8. 驗證：每款錶面匯出 1× 和 2× 平面圖，在本機跟官方並排；跑 homeplay-pet --selftest；閒置 CPU 不得高於目前。
