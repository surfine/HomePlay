錶面與眼睛檢討

拿 apple.com／homeview 上的 13 款官方錶面，逐一對照 HomePlay 目前的 9 款。結論是：材質和版式都還差一截，最大的問題是那顆眼睛膠囊。

2026-10-24 · 設計稿 v3 · 官方對照圖在 faces-v3/ref/（只放本機，不提交、不發布）

最該改黑色眼睛膠囊拿掉，換成兩顆浮在桌布上的液態玻璃眼。
玻璃字我們的數字其實是「描邊」；官方的是「實心霜玻璃」，比我們白、厚、粗。
眼睛放哪每款都放，但各自長在錶面裡：位置、大小、跟誰互動，依錶面而定；材質一律液態玻璃。
補齊陣容新增天氣、行事曆、浮雕指針、黑、Home Modular（HomeKit，見第八節）；Island 併進 Portraits。

二、逐款檢討

左邊是官方，右邊是 HomePlay 目前用 HOMEPLAY_FACE_PNG 匯出的平面錶面。

Portraits ／ Island

材質我們的數字是一條 1–2 px 的亮白描邊，裡面偏灰暗，讀起來像「空心字」。官方是整塊實心的霜玻璃：裡面比背景亮約兩成，邊緣是一圈 6–10 px 的柔光，沒有硬描邊。
字重與尺寸我們的筆畫只有字寬的約 7%；官方約 16%（Compressed Semibold 左右）。官方的數字頂到上緣，佔畫面 6%–59% 高；我們的置中，佔 10%–80%，所以人臉一定被擋住。
多餘元素日期、黑色眼睛膠囊、「重按連上 iPhone」三樣，官方都沒有。錶面上不該放操作說明。
保留主體摳圖（Vision）、數字壓在人後面的層次，方向是對的。

Photos ／ Memories

主角錯位照片錶面的主角應該是照片。我們上面壓了日期、整排描邊數字，右下還有一顆眼睛膠囊，四層東西在搶畫面。
改法分成兩款：Portraits（數字在人後面）和回憶（全幅照片加右下標題「夏天 2024」）。兩款都不放眼睛。

Modular

網格被打破眼睛膠囊浮在上下兩排中間，不屬於任何一格。
字重不一「24」用 Heavy，「100%」卻是細字。官方的「1」和「54°」都是 Heavy，小字是 Semibold，只有兩級。
像 App 圖示藍色 CarPlay 方塊看起來是 App 圖示，不是小工具。官方左下是正在播放：封面、曲名、玻璃膠囊「Play」。
改法2×2 網格：左上日期、右上指針、左下 iPhone 正在播放、右下一格「眼睛」（電量移進眼睛格下方的一行小字）。

Flow

像貼紙我們是 SF Rounded Heavy 加白描邊、平塗漸層，讀起來是「貼紙」。官方的數字被吹成鼓起的水珠，筆畫彼此融合，沒有描邊。裡面是強烈折射的粉藍漩渦，旁邊還有幾顆衛星小水珠。
改法先做 metaball 融合，再用系統玻璃管線（SystemGlass 的 SDF）上材質。其中兩顆衛星水珠帶瞳孔，就是眼睛，跟著人移動。

Typograph ／ Analog

最接近數字疊壓、綠底、白指針都做到了。
要改右下的眼睛膠囊壓到指針掃過的範圍。秒針要更細，而且要貫穿全高。

其餘三款（HomePlay 自有）

Pocket內容跟 Modular 重複，電量卡又跟背景的玻璃材質不一致。併進 Modular。
Growth點陣環是好點子，但中間又放一顆眼睛膠囊。拿掉膠囊，讓陪伴天數當主角。
床頭紅色霓虹細字有光暈，太刺眼，夜裡反而不平和。改成「黑」錶面，夜間才浮出暗紅、無光暈的時間，下面那顆暗紅膠囊也拿掉。

四、眼睛檢討

官方 13 款錶面裡沒有一款有眼睛，也沒有島。眼睛是 HomePlay 自己加的，也是它的靈魂，所以每款都要有；問題在於現在是「貼上去」，不是「長出來」。

1. 黑膠囊是硬體挖孔它把 Dynamic Island 的不透明黑塊搬上了錶面。HomeView 的視覺語言是「玻璃浮在桌布上」，而黑膠囊是整個畫面裡最重的東西，搶走了時間的主角位。
2. 材質不同語系👀 照的是 Apple Color Emoji 的擬物畫風：棕金虹膜、枕形陰影。放在玻璃數字旁邊，看起來像貼紙。
3. 每款都貼同一顆位置、大小、樣子每款都一樣，像蓋上去的印章：照片款擋到臉、Modular 打破網格、Typograph 壓到指針、床頭夜裡也亮著。眼睛要每款都在，就得每款各自設計它住在哪。
4. 結構上離不開黑底drawEye 的眼皮和笑眼都是「塗黑」遮出來的（g.setFillColor(.black)），所以只能活在黑膠囊裡。要改成玻璃，眼皮必須改成「眼睛形狀本身變形」。
5. 尺寸一律膠囊固定佔畫面寬 41%，不管在哪款錶面上。

五、液態玻璃眼

沒有容器，兩顆眼睛直接浮在桌布上，跟數字是同一種玻璃。眼白是乳白的霜玻璃，會放大並柔化後面的桌布；瞳孔是一顆深色的實心玻璃珠，左上一顆高光，右下透出一點桌布色的焦散光。眨眼、笑、睏都由玻璃形狀本身變形完成，不再靠塗黑。

六、新陣容樣稿

以下是瀏覽器裡的近似稿，用來定版式、比例和材質；App 裡的玻璃用 SystemGlass 管線實作。時間一律 10:09，日期是 2026 年 10 月 24 日（週六）。

七、實作順序

  1. 玻璃眼：新增 Faces/GlassEyes.swift，把眼睛形狀（含眼皮切口）畫成遮罩，餵給 SystemGlass 的 SDF。瞳孔另外畫一層。FaceParams 拿掉 cw/ch（膠囊），top/bot/smile/tilt 改成形狀參數。只在表情過渡時才重算 SDF（30 fps），靜止時用快取。
  2. 放置 API：每款錶面回答 eyeSlot（位置、眼高、層級：在主體前或後、在指針下），照上表；拿掉所有錶面裡的膠囊。
  3. 玻璃字：調 Portraits 的字重、位置和填充（照第三節）；拿掉日期和「重按連上」。「重按連上」改成第一次啟動或人靠近時的一次性提示。
  4. 新錶面：眼睛、天氣、行事曆、浮雕指針、黑，再重做 Modular 和 Flow；Pocket 併進 Modular。Home Modular 等第八節的路線定了再做。
  5. 驗證：每款錶面匯出 1× 和 2× 平面圖，跟官方並排；homeplay-pet --selftest；bench 閒置 CPU 不超過目前值。

天氣用 WeatherKit 需要開發者帳號的權限；不行的話改用 Open-Meteo（免金鑰）。行事曆用 EventKit，要先申請權限。

八、在 Mac 上接 HomeKit

結論：第一方 HomeKit 在 Mac 上只有 Mac Catalyst 版本，而且一定要帶 com.apple.developer.homekit 權限和描述檔。我們用 Developer ID 公開發布的 HomePlay.app 本身帶不了這個權限；可行的做法是另外做一個小幫手 App，再把家庭狀態交給桌寵。

本機實測（macOS 27.0.1）

試法結果
原生 AppKit 連結 HomeKit做不到。SDK 只在 System/iOSSupport 有 HomeKit（Catalyst 專用），原生 macOS 目標無法 import
Catalyst，不帶權限能啟動（要有 NSHomeKitUsageDescription，否則 TCC 直接中止）。authorizationStatus=5，但 homes=0，delegate 不回呼：拿不到任何資料
Catalyst，帶權限，ad-hoc 簽名一啟動就被 AMFI 殺掉（exit 137）：受限權限需要描述檔
Catalyst，Xcode 自動簽名（團隊 DQ45KFVHJ8）卡在「這台 Mac 還沒註冊到開發者帳號」。註冊會改到你的帳號，等你同意才會做
Developer ID 發布社群回報：Mac Catalyst 的 Developer ID 描述檔不提供 HomeKit（App Groups、Shared with You 也一樣），只有 App Store 和開發描述檔可以

路線比較

路線誰能用讀狀態控制代價
A. 開發簽名的 Catalyst 小幫手註冊過的 Mac（帳號每年 100 台）即時（HMAccessoryDelegate）✓只有你和註冊過的機器能跑；描述檔一年要續
B. App Store 上架「HomePlay 家庭」所有人即時✓要過審核：本身要有像樣的家庭儀表板，避免被判定成功能太少（4.2）。與 HomePlay 用同團隊 App Group 交換資料
C. 捷徑橋接（/usr/bin/shortcuts）所有人，免權限慢（每次 0.5–1 s），配件要在捷徑裡選好✓（「控制家庭」動作）使用者要匯入並設定一個捷徑
D. 私有 API（homed XPC）只有關掉 SIP 和 AMFI 的 Mac✓✓com.apple.homekit.private-spi-access 這類權限只放行 Apple 簽名；一般使用者跑不了，不能發布
E. 經 CarPlay 叫 iPhone 的 Siri所有連上 iPhone 的人✗✓（用合成語音說「打開客廳燈」）慢、Siri 會唸回覆；只能當最後的退路

建議：先做 A，讓你自己的機器馬上看到真實的 Home Modular（溫控、燈、門鎖的即時狀態）。同時把 B 當公開版本準備，C 給沒有小幫手的人當退路。小幫手和桌寵之間走本機 XPC，資料只有房間、配件名稱和狀態，不離開這台 Mac。私有 API 這條我實際查過，結論是做不到可以給別人用的版本，所以不採用。
