# 首次連線流程（設計，2026-10-25）

目標：插線立刻能用；插線一次之後就無線（宣傳）；沒有線也能第一次就無線。

## A. 有線（插線立刻能用 → 之後無線）
1. 插線 → iPhone 解鎖點「信任」→ **有線畫面立刻出**（不等藍牙、不等 Wi‑Fi）。量圓角的那一次重開，手機掛線就自動重送（ConnectionMachine 9b）。
2. 有線畫面播著的同時，背景把「之後無線」要的三件事備好，只用頂端膠囊的小提示，不擋畫面：
   - 藍牙配對：Mac 保持可被發現（車用音響類別）；提示「在 iPhone 藍牙「其他裝置」點這台 Mac，之後拔線就無線」。已配對就不提示。
   - Wi‑Fi 名稱：讀不到就在這時請定位權限（說明卡 → 系統框），被拒才手填。
   - 都備好 → 膠囊提示「拔線就能無線」。
3. 拔線 → 會話接到藍牙＋Wi‑Fi，畫面不斷（線本來就只充電時）或凍幾秒再接上。
4. 兩邊配對不同步（Mac 記得、iPhone 忘了）：拔線後查不到 iAP2 服務 → 立刻開重新配對引導（不空轉）。

## B. 無線（沒有線的第一次）
1. 第一次打開：連接步驟卡先講對的路：iPhone 設定 › 藍牙 › 其他裝置點這台 Mac（Mac 這時可被發現）；iPhone 說「不支援」別理它、別點忽略。
2. **同一張卡就先把 Wi‑Fi 名稱備好**（請定位權限），不要等手機卡住才問——避免「iPhone 要連『未知 Wi‑Fi』」。
3. 配好 → iPhone 跳 CarPlay 提示點「連接」→ 手機照 Wi‑Fi 設定連回 → 出畫面。
4. 每個關卡卡住都有一張說原因、說下一步的卡；40 秒還不行就建議「插線一次」（走 A）並提供拷貝診斷報告。

## 驗收（真機）
- A：插線到出畫面 ≤ 3 s；拔線後 ≤ 10 s 無線畫面；全程不需要使用者手動進系統設定（除了 iPhone 上點信任／配對／連接）。
- B：從打開 App 到出畫面，只需要：iPhone 藍牙點 Mac、兩邊配對、允許定位、點連接。
- 兩邊配對不同步、Wi‑Fi 名稱讀不到、手機已在同一 Wi‑Fi、防火牆開著：都有對應卡片並能恢復。
